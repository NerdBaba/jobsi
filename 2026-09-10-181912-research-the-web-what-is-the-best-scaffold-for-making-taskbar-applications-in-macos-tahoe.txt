 ▪ Based on my research, here are the best scaffolds/frameworks for building
   macOS dock/taskbar applications in 2026:

   Top Recommendations:

   1. SwiftUI (Native) ⭐ Best for Native Integration

   - Built directly into Apple's ecosystem
   - Full access to macOS Tahoe features
   - Seamless menu bar and dock integration
   - No third-party dependencies
   - Steeper learning curve if you're not already familiar with Swift

   Reference: Build a macOS menu bar utility in SwiftUI
   (https://nilcoalescing.com/blog/BuildAMacOSMenuBarUtilityInSwiftUI)

   2. Tauri v2 ⭐ Best Modern Cross-Platform Option

   - Lightweight Rust backend with web frontend
   - Excellent tray/menu bar plugin support via positioner module
   - Small binary size compared to Electron
   - Can hide from Dock for "completely invisible utility app behavior" when
   using tray events
   - Vibrancy/glass visual effects supported

   Key considerations from Tauri guides:
   - Need to skip taskbar in JSON config
   - Remove window decorations
   - Use on_tray_event() for proper visibility toggling
   - Enable vibrancy module for glass effects

   Reference: Complete Guide to Building a macOS Menu Bar App with Tauri v2
   (https://dev.to/hiyoyok/complete-guide-to-building-a-macos-menu-bar-app-with-
   tauri-v2-aji)

   3. Electron (Traditional but Heavy)

   - Largest ecosystem and community
   - Largest bundle sizes
   - More mature menu bar APIs
   - Generally discouraged for simple menu bar apps due to resource usage

   My Recommendation:

   For macOS-only utilities: SwiftUI (best native integration)

   For cross-platform with modern tech stack: Tauri v2 (lightweight, growing
   ecosystem)
